## 已核实的数据事实（2026-10-02，Claude Code 2.1.280）

- 会话记录：`~/.claude/projects/<编码目录>/<sessionId>.jsonl`。**目录名对非 ASCII 字符有损编码**（中文变 `-`），必须用记录内的 `cwd` 字段确定所属目录，不能反解目录名。
- 标题类记录会在文件中**反复追加**，最新的一条在最后，读文件尾部即可：
  - `{"type":"custom-title","customTitle":"…","sessionId":"…"}`（用户 `/rename`）
  - `{"type":"ai-title","aiTitle":"…","sessionId":"…"}`（自动标题）
  - `{"type":"last-prompt","lastPrompt":"…","leafUuid":"…","sessionId":"…"}`（`lastPrompt` 可能缺省）
- `cwd` 出现在大多数普通记录（如 `attachment`、`user`）中，文件前几行内即可找到。
- 单个文件可达 100MB+，**禁止整文件读取**：标题读尾部 256KB，cwd 读头部 64KB。

## 显示规则

- **会话标题**：`customTitle` → `aiTitle` → `lastPrompt` 前 20 个字符（单行化，去掉换行）→ 登记文件里的 `name`（仅当 `nameSource != derived`）→ 「新会话」。**不再显示 `#63` 这类编号。**
- **悬停提示**：完整标题 + 换行 + 运行位置（「在 CC Desk 内运行」/「在 Terminal 中运行，点击跳转」/「在 VS Code 中运行，点击跳转」）+ 有 lastPrompt 时「最近：…」。
- **相对时间（中文）**：<1 分钟「刚刚」，<1 小时「N分钟」，<1 天「N小时」，<7 天「N天」，否则「N周」；无时间为空串。
- **状态色**（见界面稿 CSS 变量，浅色 / 深色各一套）：等批准 = 陶土橙 `#C4552B`（深色 `#E2875F`），处理中 = 雾蓝 `#3F6E9E`（深色 `#82A8CF`），空闲 = 暖灰，目录缺失 = 灰玫瑰 `#8E5A55`。

## Task A：核心库（CCDeskCore，TDD）

**A1 `TranscriptReader`**（新文件 `TranscriptReader.swift`）
- `static func meta(fromTail data: Data) -> TranscriptMeta`：逐行（容忍首行残缺）解析，取最后出现的 `customTitle`、`aiTitle`、带文本的 `lastPrompt`。
- `static func cwd(fromHead data: Data) -> String?`：第一个含 `cwd` 字段的记录。
- `struct TranscriptMeta { customTitle, aiTitle, lastPrompt: String? }`，`displayTitle(fallbackName:) -> String` 实现上面的标题规则。
- 文件读取：`readTail(url, bytes: 256*1024)`、`readHead(url, bytes: 64*1024)`，用 `FileHandle.seek`，不整文件读。
- 测试：合成多行 JSONL（含残缺首行、多次 ai-title 取最后、lastPrompt 缺省、custom 优先）。

**A2 `TranscriptIndex`**（新文件，非线程安全 class，仅在 poll 串行队列使用）
- `init(root: URL = ~/.claude/projects, fileManager)`。
- `func meta(forSession id: String) -> TranscriptMeta?`：首次通过枚举 `root/*/<id>.jsonl` 定位并缓存路径；按 `(path, mtime, size)` 缓存解析结果，未变化不重读。
- `func history(excluding live: Set<String>, limit: Int = 300) -> [HistoryItem]`：枚举所有 `*.jsonl`，按 mtime 倒序；对每个文件缓存 `(mtime,size)→(cwd, meta)`；跳过 live 的 sessionId 和无 cwd 的文件。
- `struct HistoryItem { sessionID, cwd, title, lastPrompt?, modifiedAt }`。
- 测试：临时目录造 3 个项目、若干 jsonl（含中文 cwd、无 cwd 文件），验证分组字段、排除 live、mtime 排序、缓存命中（改写文件后 mtime 变化才刷新）。

**A3 `RelativeTime` 中文化**：改 `RelativeTime.short` 为上面的中文规则，更新测试。

**A4 Sidebar 模型调整**（`Sidebar.swift`）
- `SidebarRow.displayName` 改用 A1 的标题规则：`SidebarBuilder.build` 新增参数 `titles: (AgentSession) -> TranscriptMeta?`（默认返回 nil 以保持旧调用可编译），去掉「#编号」逻辑及其测试。
- `SidebarRow` 新增 `tooltip: String`（悬停文本，规则见上）。
- `SessionGroup` 新增 `counts: (waiting: Int, working: Int, idle: Int)`（或三个 Int 属性）。
- 历史分组工具：`HistoryGrouping.byDay(_ items:, now:) -> [(label: String, items:)]`，标签「今天 / 昨天 / 更早」，组内按时间倒序；`HistoryGrouping.forProject(root:, items:, resolver)`。
- 测试覆盖以上。

## Task B：App 层（CCDesk）

**B1 数据接线**（`AppModel`）
- poll 队列持有一个 `TranscriptIndex`；每次 poll 为 live 会话取 meta 传给 `SidebarBuilder`。
- 历史：启动时与每 30 秒在后台刷新一次 `history(excluding:)`，结果存 `@Published historyItems`；打开弹出层 / 搜索面板时立即刷新一次。
- 动作 `resumeHistory(_ item:)`：canonical cwd；目录不存在→提示；否则新建内嵌终端执行 `claude --resume <id>`，选中它。

**B2 侧栏视图**（`Views.swift` 拆分为 `SidebarView.swift`、`SessionRowView.swift`、`HistoryViews.swift`、`Theme.swift`，每个文件单一职责）
- `Theme.swift`：浅色 / 深色两套颜色常量（直接取界面稿 `:root` 与 dark 变量），通过 `@Environment(\.colorScheme)` 选择。
- 目录行（28pt 高，整行可点切换折叠，悬停整行 hover 底色）：文件夹 SF Symbol（`folder`，14pt，与会话图标列居中对齐）、目录名（13pt semibold，最深色）、靠右的状态计数（等批准实心橙、处理中实心雾蓝带白点、空闲灰色**仅收起时显示**）、最右折叠箭头（`chevron.down`，收起时旋转 -90°）。悬停时历史按钮（`clock`）与新建（`plus`）浮在计数位置上（不重排、不挤压名字）。
- 会话行（缩进 16pt，舒适密度）：26pt 图标块——内嵌会话为暖灰底 + `apple.terminal` 符号；外部会话为 `NSWorkspace.shared.icon(forFile:)` 取到的宿主 App 真实图标（Terminal：从进程链上找到的 `.app` 路径；VS Code：`com.microsoft.VSCode`），右上角白底小圆「↗」（`arrow.up.right`）；右下角状态点（等批准橙、处理中雾蓝呼吸、空闲不显示）。标题 12.5pt medium；第二行仅状态文字（等批准时「等批准 · 原因」橙色加粗，处理中雾蓝，空闲灰）；右侧中文相对时间。选中：白色卡片 + 1px 描边 + 轻阴影；等批准：整行浅橙底；超过 24 小时未变化：整行 55% 不透明。`.help(tooltip)` 显示悬停提示。
- 收起的目录间距 2pt，展开的目录下方 8pt。去掉 v1 的 Section 标题样式，改为自绘行（`List` 换成 `ScrollView + LazyVStack`，以便精确控制间距与 hover）。
- 底部汇总：「N 个会话 | ●N 处理中 | ●N 待处理」，0 时省略对应段。
- 工具栏：侧栏开关、新建（⌘N）、历史（`clock`，⌘⇧H）。

**B3 历史**（`HistoryViews.swift`）
- 目录弹出层：点目录行的时钟 → `.popover` 锚定该行，标题「<目录> 的历史会话 · N 条」、搜索框、列表（标题 + 时间，悬停显示「↩ 恢复」）、底部「在全部历史中搜索 ⌘⇧H」。
- 全局搜索面板：居中 sheet / overlay，搜索框（自动聚焦）、按「今天 / 昨天 / 更早」分组、每条显示标题 + 所属目录标签 + 时间；↑↓ 选择、↩ 恢复、esc 关闭。

**B4 详情区与终端主题**
- 标题栏：标题（13.5pt semibold）、「Claude · ~/路径」、右侧状态胶囊；终端铺满（去掉卡片边框），左右内边距与标题栏一致（24pt）。
- 终端跟随系统外观：浅色用 `#FFFEFC` 底 / `#2A2925` 字，深色用 `#1B1A18` 底 / `#D8D3CB` 字（SwiftTerm `nativeBackgroundColor` / `nativeForegroundColor`；外观变化时更新所有终端）。
