会话行的状态

每种颜色只表示一件事：陶土橙 = 等批准（需要你处理），鼠尾草绿 = 已完成·未读（Claude 做完一轮时你没在看；选中或跳转后消失），雾蓝 = 处理中，暖灰 = 空闲，灰玫瑰 = 目录缺失。图标表示会话在哪里运行：暖灰终端图标 = 在 CC Desk 内，Terminal / VS Code 等外部会话直接显示该应用的图标（App 中通过 NSWorkspace 读取本机已安装应用的真实图标）。

说明

  • 标题优先用你在 Claude 里 /rename 起的名字，其次是 Claude 自动生成的标题，再其次是你最近一条消息的前 20 个字；不再显示 #63 这类编号。
  • 分组按「需要处理」优先排序：有等批准的组在最前，然后是处理中的组。
  • 点分组标题（目录名）即可收起 / 展开整组；「poems」和「读书笔记」演示了收起状态。
  • 目录名后按状态分别计数，只显示不为 0 的：实心橙 = 等批准个数，实心绿 = 已完成·未读个数，实心蓝带呼吸点 = 处理中个数；灰色的空闲个数只在分组收起时显示（展开时每行都看得到，不重复）。悬停可看到文字明细。
  • 侧栏只放正在运行的会话。历史会话有两个入口：悬停目录标题点时钟，弹出该目录的历史（可搜索）；点左上角工具栏的时钟或按 ⌘⇧H，打开全局搜索面板，按今天 / 昨天 / 更早分组，每条标出所属目录。这里默认展开了 herdr 的弹出层。
  • 浅色外观下终端也是浅色；需要在 Claude 里执行 /theme 切到 light，否则部分灰色文字看不清。设置里可以选「终端始终深色」。
  • 标题过长：侧栏单行、末尾省略号，悬停显示完整标题和你最近一条消息；选中后右侧标题栏显示完整标题；侧栏右边缘可拖动，宽度 240–420px。目录名过长同样截断，数量标签始终完整。「旅行攻略」第二条是超长标题示例。
  • 示例里的会话标题和历史记录是示意内容，实际会从 Claude 的会话记录读取。
